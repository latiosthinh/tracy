    - Test 3: generateMatrixJUnitXML formats XML testsuites partitioned by browser (`[chromium]`, `[firefox]`, `[webkit]`) with test counts, failures, and step durations.
    - Test 4: formatMatrixConsoleReport generates an ASCII matrix summary table showing browser columns vs flow rows with pass/fail/skipped badges.

1. Update `cli/types.ts`:
   - Extend `CliOptions`:
     - `browsers?: Array<'chromium' | 'firefox' | 'webkit'>;` (default: `['chromium']`)
     - `workers?: number;` (default: auto from CPU count)
   - Extend `CliTestResult`:
     - `browser?: 'chromium' | 'firefox' | 'webkit';`
   - Define `CliMatrixResult`:
     ```typescript
     export interface CliMatrixResult {
       totalExecutions: number;
       passedExecutions: number;
       failedExecutions: number;
       skippedExecutions: number;
       totalDurationMs: number;
       browsers: Array<'chromium' | 'firefox' | 'webkit'>;
       flowResults: Map<string, Record<string, CliTestResult>>;
       results: CliTestResult[];
       startTime: string;
       endTime: string;
     }
     ```

   - Add CLI options to `node:util.parseArgs`:
     - `browsers`: `{ type: 'string', short: 'B', default: 'chromium' }`
     - `workers`: `{ type: 'string', short: 'w' }`
   - In argument normalization:
     - Split `browsers` string by comma and trim each item. Validate that each target is in `['chromium', 'firefox', 'webkit']`. If invalid, push error to `errors` array.
     - Parse `workers` as positive integer if provided.
   - Update `printHelp()` to display `--browsers` / `-B` and `--workers` / `-w` flags.
3. Update `cli/reporters/junitReporter.ts`:
   - Implement `generateMatrixJUnitXML(matrixResult: CliMatrixResult, suiteName?: string): string`:
     - For each browser target, create `<testsuite name="[${browser}] ${flowName}" tests="..." failures="..." errors="0" time="...">`.
     - Group test cases by step.
     - If step was skipped via conditional, format as `<skipped message="${step.skippedReason}"/>`.
     - If step failed, format as `<failure message="${escape(step.error)}">${escape(step.error)}</failure>`.
4. Update `cli/reporters/consoleReporter.ts`:
   - Implement `formatMatrixConsoleReport(matrixResult: CliMatrixResult): string`:
     - Render matrix summary grid:
       ```text
       ┌───────────────────────────┬──────────┬─────────┬────────┐
       │ Flow                      │ Chromium │ Firefox │ WebKit │
       ├───────────────────────────┼──────────┼─────────┼────────┤
       │ flows/login.yaml          │  PASS    │  PASS   │  PASS  │
       │ flows/checkout.yaml       │  PASS    │  FAIL   │  PASS  │
       └───────────────────────────┴──────────┴─────────┴────────┘
       ```
     - Include total duration, worker concurrency count, and breakdown of passed/failed flows.
5. Update unit tests in `cli/parseArgs.test.ts` and `cli/reporters/junitReporter.test.ts`.
