    - Test 1: shouldExecuteStepForBrowser returns true when step has no conditionals, false when when.browser mismatches, and false when skip_if.browser matches.
    - Test 2: MatrixWorkerPool initializes with default concurrency bounded to Math.max(1, Math.floor(os.cpus().length / 2)) or user-specified maxWorkers.
    - Test 3: MatrixWorkerPool launches Playwright chromium, firefox, and webkit engine targets dynamically with isolated contexts.
    - Test 4: MatrixWorkerPool executes batch of tasks within concurrency limits using p-limit or async semaphore queue.
    - Test 5: MatrixWorkerPool catches task errors gracefully, marks task as failed, and guarantees context and browser instances close in finally blocks.
    - Test 6: MatrixWorkerPool.destroy() terminates all active browsers and workers without leaving hanging processes.
  </behavior>
  <action>
1. Install `p-limit` if not present (or implement lightweight bounded semaphore pool):
   - Use `p-limit` / native async pool queue.
2. Create `electron/core/matrix/workerPool.ts`:
   - Implement helper `shouldExecuteStepForBrowser(step: { when?: StepWhenCondition; skip_if?: StepWhenCondition }, currentBrowser: MatrixBrowserTarget): { execute: boolean; reason?: string }`:
     - If `step.when?.browser`: check if `currentBrowser` matches string or is included in array. If not, return `{ execute: false, reason: "Skipped: when.browser does not match" }`.
     - If `step.skip_if?.browser`: check if `currentBrowser` matches string or is included in array. If matched, return `{ execute: false, reason: "Skipped: skip_if.browser matched" }`.
     - Otherwise return `{ execute: true }`.
   - Implement `MatrixWorkerPool` class:
     - Constructor accepting `options?: WorkerPoolOptions`.
     - Compute default worker limit: `options?.maxWorkers ?? Math.max(1, Math.min(4, Math.floor(os.cpus().length / 2)))`.
     - Track active `Browser` and `BrowserContext` instances in `Set<Browser>` and `Set<BrowserContext>`.
     - `async runTask<TResult>(task: MatrixTask, runner: (browser: Browser, context: BrowserContext, task: MatrixTask) => Promise<TResult>): Promise<TResult>`:
       - Acquire concurrency slot via `p-limit`.
       - Resolve Playwright engine (`chromium`, `firefox`, `webkit`) from `playwright-core`.
       - Launch browser instance with options (`headless: options.headless ?? true`, standard sandbox flags).
       - Register browser in active set.
       - Create new isolated `BrowserContext` with standard timezone (`'UTC'`), locale (`'en-US'`), and viewport settings.
       - Execute `runner(browser, context, task)`.
       - In `finally` block: unconditionally close context and browser, and remove from active tracking sets.
     - `async runTasks<TResult>(tasks: MatrixTask[], runner: (browser: Browser, context: BrowserContext, task: MatrixTask) => Promise<TResult>, onProgress?: (completed: number, total: number, result: TResult) => void): Promise<TResult[]>`:
       - Dispatches tasks concurrently through pool limit.
       - Emits progress updates.
     - `async destroy(): Promise<void>`:
       - Emergency / graceful teardown. Iterates active contexts and browsers, invokes `close()` wrapped in try/catch to suppress already-closed errors.
     - Register `process.once('exit')` / `process.once('SIGINT')` lifecycle listeners to trigger `destroy()` to eliminate zombie processes.
3. Write unit test suite in `electron/core/matrix/workerPool.test.ts`:
   - Mock Playwright `chromium`, `firefox`, `webkit` launch and context methods.
   - Test step conditional filtering across single strings and string arrays.
   - Test concurrency bounding (ensure no more than `maxWorkers` active at once).
   - Test error handling, failure aggregation, and guaranteed cleanup on runner throws.
   - Test `destroy()` terminates active browsers.
  </action>
