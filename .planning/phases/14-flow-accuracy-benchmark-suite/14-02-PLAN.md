  <name>Task 1: Implement Benchmark Scoring Engine and Comparison Report Generator</name>
  <files>
    src/lib/eval/benchmarkRunner.ts
  </files>
  <behavior>
    - `evaluateFlowAgainstFixture(candidateYaml: string, groundTruthYaml: string, htmlFixture: string)` parses candidate and ground-truth flows, queries the fixture DOM with candidate selectors, and calculates:
      - `locatorPrecision`: Percentage of candidate selectors that resolve to exactly 1 unique visible element in the fixture DOM (0-100%).
      - `stepRecall`: Percentage of functional action intent steps from ground-truth that are matched in candidate flow (matching command + target element) (0-100%).
      - `resilienceScore`: Average selector resilience score (0-100) calculated via `detectResilienceTier` and `scoreSelectorResilience`.
      - `flowPassRate`: Boolean and percentage indicator of whether all mandatory steps succeed without selector failures or syntax errors.
      - `tierDistribution`: Breakdown count of selectors by tier (TestId, AriaRole, VisibleText, StandardCss, DeepXPath).
    - `runBenchmarkSuite(evaluations: BenchmarkEvaluationTask[])`: Runs batch evaluations across multiple scenarios (Auth, Form, Table, Modal) and aggregates overall summary metrics.
    - `formatBenchmarkMarkdownReport(suiteResult: BenchmarkSuiteResult)`: Generates clean, structured Markdown summary tables comparing metrics across models/runs.
  </behavior>
  <action>
    Create `src/lib/eval/benchmarkRunner.ts` using `js-yaml`, DOM querying (via `jsdom` or browser DOM methods), and `selectorScorer.ts`:
    1. Define TypeScript interfaces: `BenchmarkMetricResult`, `BenchmarkEvaluationTask`, `BenchmarkScenarioResult`, and `BenchmarkSuiteResult`.
    2. Implement `evaluateFlowAgainstFixture` with robust step parsing, action alignment, DOM querying, and metric calculations.
    3. Implement `runBenchmarkSuite` for multi-scenario aggregation.
    4. Implement `formatBenchmarkMarkdownReport` to format the metrics matrix into a markdown table with status badges and tier distributions.
  </action>
