| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-01 | Denial of Service (Renderer Memory Bloat) | `networkStore.ts` | mitigate | Cap captured request ring buffer at max 1,000 entries; discard oldest entries when capacity exceeded. |
| T-23-02 | Denial of Service (UI Thread Freeze) | `perfStore.ts` & `networkStore.ts` | mitigate | Ingest high-frequency telemetry via 100ms micro-batch buffers instead of re-rendering on every individual packet. |
