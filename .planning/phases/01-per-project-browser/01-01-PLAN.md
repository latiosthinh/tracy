and same four channel names. Replace the singleton with a keyed registry:

```typescript
import { ipcMain, BrowserWindow, WebContentsView } from 'electron';

const MAX_LIVE_WEBVIEWS = 4;

interface WebviewEntry {
  view: WebContentsView;
  lastUsed: number;      // Date.now(), updated on open/resize (LRU)
}

const webviews = new Map<string, WebviewEntry>();

function isValidProjectId(projectId: unknown): projectId is string {
  return typeof projectId === 'string' && projectId.length > 0 && projectId.length <= 128;
}

function evictIfNeeded(parentWin: BrowserWindow): void {
  while (webviews.size > MAX_LIVE_WEBVIEWS) {
    let oldestId: string | null = null;
    let oldestTime = Infinity;
    for (const [id, entry] of webviews) {
      if (entry.lastUsed < oldestTime) { oldestTime = entry.lastUsed; oldestId = id; }
    }
    if (!oldestId) break;
    const entry = webviews.get(oldestId)!;
    parentWin.contentView.removeChildView(entry.view);
    entry.view.webContents.close();
    webviews.delete(oldestId);
  }
}
```

Handlers (payload shapes):

1. `open_child_webview` — payload `{ projectId, url, x, y, width, height }`:
   - Reject (return undefined) if `!isValidProjectId(projectId)`; console.warn with the failure.
   - Keep the EXISTING URL scheme validation block verbatim (`http://`, `https://`, `about:blank`
     only; warn + return otherwise).
   - `const parentWin = BrowserWindow.fromWebContents(event.sender); if (!parentWin) return;`
   - If `webviews.has(projectId)`: reuse entry — update `lastUsed = Date.now()`;
     if view is not attached to `parentWin.contentView` (track via try/catch-free approach:
     always call `parentWin.contentView.addChildView(entry.view)` — Electron no-ops on re-add of
     already-attached view is NOT guaranteed, so wrap: removeChildView inside try/catch then
     addChildView), then `setBounds({x,y,width,height})` rounded with Math.round, and
     `if (entry.view.webContents.getURL() !== url) entry.view.webContents.loadURL(url);`
     (D-07: skip reload when URL unchanged — no flicker on project tab switch).
   - Else create fresh:
     ```typescript
     const view = new WebContentsView({
       webPreferences: {
         contextIsolation: true,
         nodeIntegration: false,
         sandbox: true,
       },
     });
     ```
     (D-06 security — keep these exact three flags), `parentWin.contentView.addChildView(view)`,
     setBounds rounded, `view.webContents.loadURL(url)`, store
     `webviews.set(projectId, { view, lastUsed: Date.now() })`, then `evictIfNeeded(parentWin)`.

2. `resize_child_webview` — payload `{ projectId, x, y, width, height }`:
   - If invalid projectId or no entry: return. Else `entry.view.setBounds(...)` (Math.round),
     `entry.lastUsed = Date.now()`.

3. `set_child_webview_visible` — payload `{ projectId, visible }`:
   - If invalid projectId or no entry: return. If `visible === false`:
     `entry.view.setBounds({ x: 0, y: 0, width: 0, height: 0 })`. If true: no-op
     (frontend calls resize right after — preserve existing semantics).

4. `close_child_webview` — payload `{ projectId }`:
   - If invalid projectId: return. If entry exists: `parentWin` from event.sender;
     removeChildView, `entry.view.webContents.close()`, `webviews.delete(projectId)`.
