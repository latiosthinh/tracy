<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Renderer -> Main Process (`validate_dom_selector`) | Untrusted selector string and parameters sent across IPC bridge |
| Main Process -> Child Webview (`executeJavaScript`) | Script evaluated inside target web page context |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-01 | Injection / Tampering | `electron/ipc/webviewManager.ts` | mitigate | Pass selector as a JSON-serialized parameter string to `executeJavaScript` rather than direct string interpolation to prevent JS injection breakouts in target page. |
| T-10-02 | Denial of Service | `electron/ipc/webviewManager.ts` | mitigate | Bound selector probe execution with a strict timeout (e.g. 2000ms max) and cap match return count to 10 elements to avoid memory/IPC bottlenecks. |
| T-10-03 | Elevation of Privilege | `electron/preload.ts` | mitigate | Strict channel whitelist enforcement in preload context bridge preventing unauthorized IPC channel calls. |
</threat_model>
