<task type="auto" tdd="true">
  <name>Task 2: Implement Selector Resilience Scorer & Unit Test Suite</name>
  <files>src/utils/selectorScorer.ts, src/utils/selectorScorer.test.ts</files>
  <behavior>
    - Classifies probe results:
      - 1 visible match -> `UniquePresent`
      - >1 matches -> `AmbiguousMultiple`
      - 0 matches without dynamic context -> `NotPresent`
      - 0 matches with preceding trigger action (e.g. click modal/menu/accordion) -> `DeferredDynamic`
    - Classifies selector tier & base score:
      - `[data-testid=...]`, `[data-test=...]`, `data-cy=...` -> `TestId` (score: 100)
      - `role=...`, `aria-label=...`, `[role=...]`, `getByRole(...)` -> `AriaRole` (score: 85)
      - `text=...`, `has-text(...)` -> `VisibleText` (score: 70)
      - Standard tag/class/id like `#submit`, `.btn-primary` -> `StandardCss` (score: 50)
      - Deep nth-child, complex chained xpath `//div/div[2]/button` -> `DeepXPath` (score: 20)
    - Deducts penalties for fragility:
      - Ambiguous multiple matches (-30)
      - Hidden / invisible elements (-40)
      - Long/fragile path lengths (> 60 chars or > 4 combinators: -15)
      - Autogenerated IDs/classes (hashes like `.css-19vjh7`, `#btn-823472`: -25)
    - Returns `isReliable: true` when score >= 70 and status is `UniquePresent` (or `DeferredDynamic` if high tier).
    - Suggests actionable alternative selectors based on probe match metadata (e.g. recommending testId or role/name if present on matched element).
  </behavior>
  <action>
    1. Create `src/utils/selectorScorer.test.ts` testing:
       - Tier detection across testid, aria/role, text, standard css, and deep xpath.
       - Presence categorization for unique, multiple, absent, and dynamic deferred selectors.
       - Penalty deductions (fragility, length, hashes, invisibility).
       - Suggestion generation when element has testId or aria attributes.
    2. Create `src/utils/selectorScorer.ts` implementing:
       - `detectResilienceTier(selector: string): SelectorResilienceTier`
       - `classifyPresenceStatus(probeResult: SelectorValidationResult, precedingSteps?: PrecedingStepContext[]): SelectorPresenceStatus`
       - `isDynamicTriggerStep(step: PrecedingStepContext): boolean`
       - `isAutoGeneratedSelector(selector: string): boolean`
       - `scoreSelectorResilience(selector: string, probeResult?: SelectorValidationResult, precedingSteps?: PrecedingStepContext[]): SelectorScoreReport`
       - `rankSelectorsByResilience(candidates: string[], probeResults?: Map<string, SelectorValidationResult>): SelectorScoreReport[]`
