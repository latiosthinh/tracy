## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Test Flow YAML -> NetworkMockManager | User-defined URL regexes and fixture file paths loaded into main process. |
| Browser Network Stack -> Playwright Route | Intercepted in-flight HTTP requests and response buffers. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-01 | Tampering / Path Traversal | `networkMockManager.ts` | mitigate | Sanitize fixture file paths using `path.resolve` and prevent access outside permitted workspace directories. |
| T-20-02 | Denial of Service (ReDoS) | `networkMockManager.ts` | mitigate | Safe regex compilation with try/catch and fallback to string matching on regex compilation failure. |
| T-20-03 | Denial of Service (Hanging Sockets) | `networkMockManager.ts` | mitigate | Always invoke `route.fallback()` or `route.fulfill()` in a terminal try/catch block so no request hangs open. |
| T-20-04 | Information Disclosure | `networkMockManager.ts` | mitigate | Cap captured request ring buffer at 500 entries to prevent memory exhaustion during long runs. |
</threat_model>
