# Requirements: ProQA

## Milestone v3.0 — AI Flow Gen V2 & Dynamic Agent Skills

### SKILL — Declarative Agent Skills Runtime & Registry

**SKILL-01: Declarative Skill Definition Schema**
Structured schema for defining reusable agent capabilities with metadata, parameters, prompt modifiers, and tools.
Acceptance:
- Type-safe skill definition schema supporting name, description, tags, target domain, system prompt injection, and tool schemas
- Built-in validation using standard schema validation
- Serialization to and from declarative `.skill.json` / `.skill.yaml` formats

**SKILL-02: Skills Store & Registry Engine**
Centralized registry for discovering, registering, enabling, and disabling agent skills.
Acceptance:
- Registry supports built-in bundled skills and dynamic project-level custom skills
- Active skill set is accessible to AI providers and Copilot UI via Zustand store (`agentStore`)
- Ability to toggle skills individually or select preset skill packs

---

### VERIFY — Live DOM Selector Pre-Validation Engine

**VERIFY-01: Isolated-World Webview Selector Prober**
Fast Electron main IPC service to test and measure CSS, XPath, Text, and ARIA selectors against live `WebContentsView`.
Acceptance:
- Parameterized execution in isolated script context (prevents page script pollution and injection)
- Returns match count, visibility state, bounding box, tag name, text content, and shadow DOM penetration
- Safe timeout handling without blocking the Electron main thread

**VERIFY-02: Selector Robustness & Ambiguity Tagging**
Categorize selectors by stability score and dynamic execution timing.
Acceptance:
- Classifies locators as `UniquePresent`, `AmbiguousMultiple`, `NotPresent`, or `DeferredDynamic` (for elements revealed by preceding steps)
- Computes fallback resilience hierarchy (TestID > Role/ARIA > Visible Text > Unique CSS/XPath)

---

### TOOL — Multi-Provider Self-Healing Tool Calling Loop

**TOOL-01: Multi-Provider Tool Calling Abstraction**
Unified tool-calling bridge supporting Google GenAI, OpenAI-compat, Anthropic, and local CLI stdin runners.
Acceptance:
- Exposes `validate_selector`, `find_elements_by_text`, and `inspect_element` as native tool definitions
- Translates tool calls and returns results across Google, Anthropic, and OpenAI API protocols

**TOOL-02: Bounded Self-Correction & Loop Guard**
Multi-turn agent loop that repairs fragile selectors before producing the final YAML flow.
Acceptance:
- If a proposed selector fails validation, agent receives diagnostic error and re-selects alternative locator
- Strict iteration cap (maximum 5 turns), token usage ceiling, and loop detection to prevent runaway executions
- Emits real-time agent thought traces and tool execution events via IPC

---

### DOMAIN — Built-in QA Domain Skills Catalog

**DOMAIN-01: Authentication & Session Edge Cases Skill**
Specialized skill for synthesized flows dealing with login, MFA input, cookie banners, and session timeouts.
Acceptance:
- Provides system heuristics for password fields, 2FA split inputs, and OAuth popups
- Generates resilient waitFor conditions and secure input handling

**DOMAIN-02: Dynamic Form & Validation Handling Skill**
Specialized skill for complex form controls, custom selects, datepickers, and client-side error states.
Acceptance:
- Emits proper blur/tab keystroke triggers and checks for `aria-invalid` / error text containers

**DOMAIN-03: Data Tables & Pagination Skill**
Specialized skill for targeting tabular data, row actions, sorting, and pagination controls.
Acceptance:
- Heuristics for relative row/column scoping and stable cell selector generation

**DOMAIN-04: Shadow DOM & Modal Overlay Skill**
Specialized skill for open shadow roots, nested iframes, backdrop dismissal, and focus-trapped dialogs.
Acceptance:
- Generates cross-boundary locators and wait strategies for animated transitions

---

### UI — AI Copilot Skill Selector & Trace Inspector

**UI-01: Copilot Skill Selector & Preset Badges**
Interactive UI in `AiCopilot.tsx` to toggle active agent skills and inspect active tool bindings.
Acceptance:
- Multi-select skill pill list with active state indicators and domain category icons
- One-click presets ("Standard QA", "Form Specialist", "Data Table Deep-Dive", "Full Power")
- Persists user skill selections per project in `agentStore`

**UI-02: Live Reasoning Trace Inspector**
Collapsible execution trace panel showing agent thinking, tool invocations, and DOM selector check results.
Acceptance:
- Displays tool invocation history with input arguments, output match results, and duration
- Redacts sensitive credentials (passwords, tokens) in trace logs
- Real-time streaming updates synchronized with Copilot generation

---

### EVAL — Flow Accuracy Benchmark Suite

**EVAL-01: Deterministic Test Fixture Suite**
Static HTML test pages and ground-truth YAML flows covering standard E2E testing scenarios.
Acceptance:
- HTML fixtures for complex forms, data tables, modal dialogs, and authentication flows
- Canonical reference flows specifying expected step actions and valid locator alternatives

**EVAL-02: Automated Flow Accuracy & Stability Benchmark**
Vitest-compatible test harness scoring model generation accuracy.
Acceptance:
- Evaluates Locator Precision (% valid unique selectors), Step Recall (% required actions captured), and Flow Pass Rate
- Reports benchmark metrics table across configured providers/models
