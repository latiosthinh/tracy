<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Tool Arguments → Webview Probe | Untrusted LLM tool call arguments executed against DOM probe |
| Tool Result → Next Prompt Turn | DOM text and match details fed back into LLM context |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01 | Tampering | `electron/ipc/aiProvider.ts` | mitigate | Sanitize tool input strings; selector argument must be string <= 1000 chars; tag names alphanumeric only |
| T-11-02 | Information Disclosure | `electron/ipc/aiProvider.ts` | mitigate | Redact API keys and authorization tokens in tool error messages and trace logs using `redactSecrets()` |
| T-11-03 | Denial of Service | `electron/ipc/aiProvider.ts` | mitigate | Bound tool input payloads to prevent oversized token injections |
</threat_model>
