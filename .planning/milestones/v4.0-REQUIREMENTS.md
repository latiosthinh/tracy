# Requirements: Milestone v4.0 (Autonomous Multi-Flow Agent & Self-Healing CI)

**Status:** Shipped 2026-08-19

## Requirements

### Self-Healing Test Runner & Auto-Repair (HEAL)
- [x] **HEAL-01**: Intercept step locator timeouts and trigger heuristic DOM fallback ranking.
- [x] **HEAL-02**: GenAI fallback locator synthesizer when local heuristic score < 0.75.
- [x] **HEAL-03**: Semantic role and action verb invariants prevent healing into contrary actions or mutating assertions.
- [x] **HEAL-04**: In-place YAML AST patcher updates selector values in disk files preserving all comments and structure.
- [x] **HEAL-05**: Step execution reports display heal badges with previous selector, replacement selector, confidence, and diff preview.

### Headless CI Runner & Reporting (CI)
- [x] **CI-01**: Standalone CLI entry point (`tracy run [path] [flags]`) executes YAML flows without Electron GUI dependencies.
- [x] **CI-02**: CLI supports `--ci`, `--heal`, `--timeout`, `--reporter`, and `--output` options via native `node:util.parseArgs`.
- [x] **CI-03**: Built-in JUnit XML reporter generates CI-compatible test results schema with step timings and failure details.
- [x] **CI-04**: Headless runner captures failure screenshots, traces, and DOM snapshot artifacts into output directory.
- [x] **CI-05**: Self-healing in CI mode produces standard `.patch` file or auto-commits repaired YAML files with clear summary logs.

### Autonomous Sitemap & Journey Crawler (CRAWL)
- [x] **CRAWL-01**: Graph-based BFS crawler explores internal routes starting from target URL within origin boundaries.
- [x] **CRAWL-02**: Structural DOM skeleton hashing identifies unique SPA dynamic views and detects cyclic states.
- [x] **CRAWL-03**: Destructive action safety filter blocks dangerous keywords (`/logout|delete|remove|destroy|signout/i`).
- [x] **CRAWL-04**: Interactive form explorer fills forms using contextual safe synthetic mock inputs.
- [x] **CRAWL-05**: Auto-flow generator compiles discovered journey paths into executable, lint-compliant YAML test suites.

### Journey & Coverage Visualizer UI (VIS)
- [x] **VIS-01**: Interactive `@xyflow/react` canvas displays discovered routes, pages, and interconnecting actions.
- [x] **VIS-02**: Graph nodes indicate test coverage status (covered by existing flow, partially tested, unvisited).
- [x] **VIS-03**: Clicking a route or edge allows one-click generation or execution of linked YAML flows directly in Studio.
- [x] **VIS-04**: Live crawl progress overlay streams newly discovered nodes, active crawler worker position, and queue count.
