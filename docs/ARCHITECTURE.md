# Architecture Overview

Tracy is built with a modern web stack embedded inside a desktop environment. This allows for rich, interactive UI combined with native file-system access and browser automation capabilities.

## High-Level Components

1. **Frontend (React & Vite)**
   - Powers the entire IDE interface.
   - Responsible for YAML editing, visual step building, and UI state.
   - Built with `TailwindCSS` for styling and `lucide-react` for iconography.

2. **Backend (Electron)**
   - Acts as the host for the application.
   - Manages file I/O operations (saving flows, parsing YAML).
   - Serves as the bridge between the Frontend and Playwright.

3. **Automation Engine (Playwright)**
   - A hidden Playwright instance runs alongside the application.
   - Executes the YAML commands against the target web application.
   - Provides visual feedback (screenshots, element outlines) to the `RealBrowserView` in the Frontend.

4. **AI Layer (Google GenAI SDK)**
   - Integrated into the `AiCopilot` component.
   - Receives DOM snapshots and natural language prompts.
   - Generates YAML flows automatically.

## State Management (Zustand)

Tracy uses `Zustand` for state management, split into specific domains:

- `projectStore.ts`: Manages projects, active flows, and file syncing.
- `executionStore.ts`: Tracks Playwright execution state, logs, and timelines.
- `uiStore.ts`: Manages active tabs, panels, and modals.
- `domSnapshotStore.ts`: Caches the DOM syntax trees generated by the `dom-miner`.
- `settingsStore.ts`: Handles user preferences and workspace configurations.

## IPC (Inter-Process Communication)

Communication between the React Frontend and the Electron Backend happens via a strongly-typed IPC bridge (`src/lib/ipc.ts`).

Example flow:
1. User clicks "Run" in `StudioView.tsx`.
2. `executionStore` calls `tracyApi.runFlow(flow)`.
3. The IPC bridge serializes the command and sends it to the Electron Main process.
4. Electron invokes Playwright.
5. Playwright streams logs back via IPC events, which `executionStore` listens to and updates the UI in real-time.
